## Theme Store

After installation or update, ZIPNATION Theme Store opens automatically.

You can reopen it from:

`Ctrl+Shift+P` → `ZIPNATION: Theme Store`

The store provides:
- visual previews
- FREE/VIP status
- theme switching
- VIP activation area
- persistent activation state

## Security

The public extension must not contain VIP master secrets, code generators, or `vip-codes.json`.

Development-only local testing is restricted to the VS Code Extension Development Host. Production paid-license validation should use a ZIPNATION server/API.
